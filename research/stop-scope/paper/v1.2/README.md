The v1.0 evidence tag and earlier manuscript versions are preserved. No DOI has been assigned to this revision by this publication step.

To rebuild the editable manuscript, install `python-docx` in a suitable environment and run `python3 -B build_docx.py` here. This optional document-generation dependency is separate from the evidence verifiers, which use Python's standard library only. PDF pagination depends on the office renderer and fonts. The released PDF was rendered with the bundled LibreOffice environment, and all eight pages were visually inspected.
