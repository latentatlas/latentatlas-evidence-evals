# R09 — Reproducible pinned-cusp shape design

Entry points: [Turkish research note](ARASTIRMA_NOTU.md),
[analytic proof](PROOF.md), [theorem fragment](THEOREM_APPENDIX.tex),
[standard sources](REFERENCES.md), [diagnostics](DIAGNOSTICS.md).

The exact Q, theta kernel normalization and previous packages R01–R08
are frozen dependencies. New results change the kernel by a specified
four-cosine multiplier. The continuum fold theorem is at ν=0, not the
whole ν arc of the previous direction.

## Environment and execution

The recorded run uses the workspace `.venv-math/bin/python` (Python
3.12), python-flint 0.9.0, mpmath 1.4.1, NumPy and Matplotlib 3.11.2.
Use `PYTHONDONTWRITEBYTECODE=1`; assertions must remain enabled.
No scipy or symbolic algebra package is required.

Run commands from the project root. Existing outputs are deliberately
not overwritten. To regenerate, copy the project or this package with
its adjacent dependencies to a scratch location, remove only the copied
R09 generated outputs and manifest, and execute these stages in order:

```sh

PYTHONDONTWRITEBYTECODE=1 .venv-math/bin/python research/cusp_shape_design/certify_design.py --output research/cusp_shape_design/results/design_certificate.json
PYTHONDONTWRITEBYTECODE=1 .venv-math/bin/python research/cusp_shape_design/check_design.py --output research/cusp_shape_design/results/design_check.json
PYTHONDONTWRITEBYTECODE=1 .venv-math/bin/python research/cusp_shape_design/build_local_jets.py --output research/cusp_shape_design/results/local_jets.json
PYTHONDONTWRITEBYTECODE=1 .venv-math/bin/python research/cusp_shape_design/certify_local_v2.py --output research/cusp_shape_design/results/local_certificate.json
```

The floating-point support search is optional: it is not an input to
the exact dual optimality proof. Reproduction should compare bounds
and mathematical pass conditions, not elapsed times or whole-file
hashes of newly timed outputs. The frozen manifests are provenance
checks for this particular recorded run.

To check preservation and all recorded source/input/output links without
rerunning quadrature:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv-math/bin/python research/cusp_shape_design/audit_snapshot.py
```

That audit is not a substitute for inspecting the analytic proof or
rerunning the independent arithmetic checkers. Original project paths
in the R01 manifest must be accessible for its preservation check.

PNG/SVG; the LaTeX fragment is provided but has not been compiled.
